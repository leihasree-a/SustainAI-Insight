🌱 SustainAI Insight

SustainAI Insight is a sustainability analytics dashboard that analyzes climate and energy data to provide insights into CO₂ emissions, renewable energy adoption, and sustainability trends across different countries.
✨ Features

* 🌍 Country-wise sustainability analysis
* 📊 Interactive monthly CO₂ emission trends
* 🌱 Renewable energy share visualization
* ⭐ Sustainability Score calculation
* 🤖 AI-based Sustainability Insights
* 📈 Top countries comparison based on CO₂ emissions
* 🔄 Dynamic dashboard updates using selected country

🛠️ Tech Stack

 Frontend

* React.js
* Tailwind CSS
* Recharts
* Axios

 Backend

* Flask
* Pandas
* Flask-CORS

 Dataset

* Climate & Energy Dataset (2020–2024)
